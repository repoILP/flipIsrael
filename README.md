# 🔗 Flappy Link — Link na Bio em formato de minijogo

Site estático de "Link na Bio" inspirado no Flappy Bird. 100% HTML/CSS/JS puro, pronto para o **GitHub Pages**.

## Estrutura
```
site_legal/
├── index.html          # Página principal (canvas + overlays + links da bio)
├── style.css           # Estilos mobile-first
├── script.js           # Lógica do jogo + ganchos de backend
├── avatar-normal.png   # Avatar do jogador (voando)  ← ADICIONE SUA IMAGEM
├── avatar-sad.png      # Avatar no game over          ← ADICIONE SUA IMAGEM
└── README.md
```

## ⚠️ Antes de publicar
1. Coloque as imagens **`avatar-normal.png`** e **`avatar-sad.png`** na raiz do projeto (mesma pasta do `index.html`). Se alguma não existir, o jogo usa um círculo amarelo como fallback (mas recomenda-se usar as imagens para o efeito de humor no game over).
2. Edite os **links da bio** no `index.html` (bloco `<!-- LINKS DA BIO -->`): Instagram, YouTube, Portfólio, Loja.

## ▶ Rodar localmente
Abra `index.html` no navegador, ou sirva a pasta:
```bash
python -m http.server 8080
# acesse http://localhost:8080
```

## 🚀 GitHub Pages
1. Suba os arquivos para um repositório.
2. Settings → Pages → Source: `main` / root.
3. O jogo fica disponível em `https://SEU_USUARIO.github.io/REPO/`.

## 🎮 Controles
- **Toque/clique** na tela ou tecla **Espaço / ↑** para pular.
- Dificuldade progressiva: canos aceleram e o vão diminui com o tempo.

## 🔌 Placar global (Supabase)
O jogo salva o recorde localmente via `localStorage` e envia a pontuação (com o nome digitado na tela inicial) para o **Supabase**.

**Configurado em `script.js` → `LINKS_CONFIG.supabase`:**
- ✅ URL: `https://vpzxrmxqkjrkxhzodovg.supabase.co`
- ⚠️ `anonKey`: **cole a anon key** do projeto (Dashboard → Settings → API) para ativar.

**Crie a tabela no SQL Editor do Supabase:**
```sql
create table pontuacoes (
  id bigint generated by default as identity primary key,
  nome text not null,
  pontuacao int not null,
  criado_em timestamptz default now()
);

-- permite que qualquer visitante insira e leia (anon key)
create policy "insert publico" on pontuacoes for insert to anon with check (true);
create policy "select publico" on pontuacoes for select to anon using (true);
```

Enquanto a `anonKey` não for preenchida, o jogo funciona normalmente salvando só localmente (sem quebrar nada). A função `buscarRanking(limite)` já está pronta para exibir um top-10 futuro.
